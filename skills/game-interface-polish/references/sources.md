# 来源、结合方式与适用边界

核对日期：2026-10-25。

## 本次实际项目

从《惊喜》双视角故事的优化中归纳：素材盘点、逐帧校准、统一动画时钟、选择/回看状态、参考风格背景生成、实际接入、横竖屏取景、真实渲染以及源码导出验证。

当时项目有13幕、3次选择、32个动作帧；背景系列使用8张图，地面/脚底约为舞台高度82%/88%。这些用于解释约束来源，不是未来项目的固定规格。已观察到的“手机整幅缩图导致家具过小”促成等比取景；当前技能不保留这个被替换的方案。

## 用户指定的两套官方技能

- [Remotion Agent Skills](https://github.com/remotion-dev/skills)：React视频项目的创建、时间轴/动画、预览与渲染指导。使用已安装版本的入口，按任务读取其子指导，不复制整套文档进本技能。
- [Hyperframes](https://github.com/heygen-com/hyperframes)：HTML/CSS媒体与可寻址动画的视频生产。主入口和CLI/组件/媒体核心指导按需调用，不把仓库所有示例、迁移和演示技能自动加入工作流。

历史整理环境中Remotion已存在，Hyperframes由用户明确要求安装；这不保证导入本包的另一台电脑已具备它们。技能安装成功与运行依赖、编码链路跑通分开报告，不覆盖已有配置。本技能负责“游戏场景目标 → 工具分流 → 验证交付”的结合层。

## 与现有能力的关系

本次导出另吸收了Love游戏迭代中的实际问题：参考风格与产品入口的边界、外侧底图、气泡自动宽度、图片加载后的重新定位、微信与长字幕避让，以及场景暂停导致选择面板透明。可复用的处理与验收方法整理在[界面分层与消息排版](ui-overlays.md)，不把该游戏的尺寸、节点数、端口、私有路径或过往通过结果作为其他项目的默认事实。

`chinese-ui-design`负责中文界面的局部设计检查；`imagegen`负责位图生成/编辑；官方视频技能负责对应框架。没有对应工具时报告能力缺口，不虚构安装、运行或模型版本。各技能只在相关任务出现时读取，保持现有项目和用户最新要求优先。
