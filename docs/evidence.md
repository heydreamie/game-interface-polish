# 对比素材与验证范围

记录日期：2026-10-25。

## 对比的是哪两个版本

案例来自同一个《惊喜》Love 游戏工程。历史基线标识为 `f3149eb`，当前演出版本标识为 `a695f9a`；它们是案例游戏仓库的提交标识，不是本 Skill 仓库的提交。

录制用历史版本与当前版本各自的真实 HTML、CSS、角色帧和播放器。为保证台词和场景可比，由临时回放页给两个播放器提供相同指令，不运行随机剧情分支；消息与对白测试不启动额外 Godot 画布。临时服务、历史工程、浏览器配置、账号和本机路径不包含在本仓库。

## 三个片段

| 视频位置 | 输入保持一致 | 可观察变化 |
| --- | --- | --- |
| 00:00–00:08 | 同一角色、同一行走指令 | 场景风格化、角色动作和纸张界面 |
| 00:08–00:16 | “我在你公司对面，给你带了饭。你现在方便说话吗？” | 窄列气泡与整句行宽 |
| 00:16–00:24 | 同一条长微信和同一段长字幕 | 底部重叠与右侧避让 |

场景回放用于展示和可重复排版对比，不替代实际游戏的选择、回退、暂停和分支测试，也不代表现场让一个陌生工程自动完成优化。

## 视频怎么制作

- 从真实浏览器页面采样，每段48帧，目标采样率6帧/秒，三个片段共144帧。
- 编码为1280×720、24秒、H.264 MP4；输出24帧/秒通过重复采样帧实现，不是游戏帧率测试。
- README 的 GIF 为960×540、6帧/秒的同一组浏览器画面。
- 无音轨、旁白或配乐；中文标题和说明在录制页面中实际排版。
- 图片是对应片段的浏览器截图，没有把改进前截图人工画坏，也没有用概念图替代当前渲染结果。

## 验证记录

Skill 格式、相对引用和导出包完整性已检查。案例当前游戏的16项剧情、动作、入口和数据测试通过；此前完整剧情240轮覆盖33节点与78选项。这些是该案例的检查范围，不能据此声称适用于所有项目。

对消息与气泡的实际浏览器检查包括桌面和390×844手机视口、同句长台词、左右角色、靠边人物、首次图片加载、单条与连续长消息、聊天回忆和长字幕。消息区与字幕区留有间距，超长记录可滚动，自动播放到选择处时面板可见。

本仓库的视频主要展示桌面画面。实体手机、所有浏览器兼容性、音效听感和公网性能不在本次视频的证明范围内。
